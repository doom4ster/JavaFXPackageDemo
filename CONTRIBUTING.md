# Contributing to the JavaFX Packaging Demo

The guidelines for contributing to the project are quite simple:

- Anyone is free to add their own insight to the guide via PRs. 
- Contributions to the documentation, `pom.xml` or helper Java Classes, and Github related contributions (for things such
    as issue templates) are welcome.
- All contributions will be reviewed for both accuracy and clarity.
- The use of LLMs for either code or documentation is strictly **banned** for this project. This project is about those
with experience with JavaFX passing down their knowledge directly to new users. LLMs can hallucinate, obfuscate even
simple concepts behind verbose / hard to understand language and, in my opinion as an educator, counter-productive for
the use-case of teaching. As such, **LLM contributions are NOT welcome in this project**

Thank you for considering to contribute to this project! Every new contribution is us getting one step closer to ironing out
the pain-points of learning the JavaFX framework!
